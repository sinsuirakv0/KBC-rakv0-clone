# ロードマップ

## v0.1

- 対話メニュー
- 複数クローン作成
- ローカル台帳
- 本家・クローンの起動とAndroid管理画面
- 同じ署名鍵によるクローン更新
- ABI確認と動作診断

## v0.2

- 固定プレフィックス＋任意識別子によるパッケージ指定
- アプリ名とPNGアイコンの指定
- 指定アイコンの保存と更新時の再利用
- 初見向け作成・更新ウィザード
- XAPK展開結果の高速キャッシュ
- 署名鍵のバックアップ・復元
- 更新前バックアップ
- ビルド履歴とログ表示
- ダウンロード済みXAPKの整理
- 失敗からの再開

## v0.3

- メニューとCLIからの自己更新
- 更新後の自動再起動
- 任意導入のAndroid連携アプリ
- 本家・クローンの正確なインストール状態
- インストール済みversionCode/versionNameの取得
- 更新可能状態の自動判定

## 検討中

- APKComboなどの利用条件に沿った最新版取得補助
- GitHub Releasesからのツール自身の更新
- バックグラウンド更新通知
- 複数言語対応

最新版XAPKの自動取得は、一時URLや配布元の仕様変更へ依存する。固定URLの埋込みは行わず、配布元の利用条件と安定性を確認してから実装する。
